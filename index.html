商品一覧を更新する（荻原さん用）

在庫CSVから追加（ロジレスの在庫一覧 ActualInventorySummaries）

  1. 「一覧を編集する」で直すか、CSVで追加する
  2. 「products.json を書き出す」でファイルを保存する
  3. GitHub の kanban-kun を開き「Add file → Upload files」で products.json を上げて「Commit changes」
  4. 1〜2分後、全員のカンバン君に反映（反映されたらこのPCの「編集を取り消す」を押す）
